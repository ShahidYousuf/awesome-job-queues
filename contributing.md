# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](https://github.com/sindresorhus/awesome/blob/main/code-of-conduct.md). By participating in this project you agree to abide by its terms.

## Adding an entry

- Open one pull request per entry.
- Use the format `- [Name](link) - Description.`
- Keep the description short and factual. Say what the project does, not how good it is.
- Add the entry to the relevant section, in alphabetical order.
- The project must be maintained: no archived, deprecated or abandoned projects.
- Check your spelling and grammar.
- Make sure your text editor removes trailing whitespace.

## Updating an entry

If a project is archived, renamed or has moved, open a pull request or an issue with a link that shows the change.
